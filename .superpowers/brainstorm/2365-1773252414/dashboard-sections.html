AI Chat (core — always included)

The main advisor interface with SSE streaming, message history, and follow-up pills.

My Profile

User details form: age, income, smoker status, occupation, dependents. Pre-fills the chat context automatically.

⊞

Plan Comparison

Side-by-side table of recommended plans with sortable columns, filters by premium/CSR/cover, highlight best value.

◷

Conversation History

Past chat sessions with search, resume any thread, timestamps. Shows session summaries.

◫

Policy Library

Browse all available insurance plans by company/type. Expandable cards with riders, benefits, exclusions.

◎

Saved Quotes

Plans saved from chat sessions. Download PDF, compare, or share. Quick re-calculate with updated profile.

Sidebar Preview

AI Chat is always first. Others follow in order selected.

💡 Recommendation: Start with Chat + Profile + Plan Comparison + History. These 4 make the strongest product with the least implementation complexity. Policy Library and Saved Quotes can be added later.
